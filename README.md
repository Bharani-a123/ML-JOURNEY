## How to Run

### Option 1: Run locally (recommended)
1. Clone the repo:
   ```bash
   git clone https://github.com/Bharani-a123/ML-JOURNEY.git
   cd ML-JOURNEY
   ```
2. Create and activate a virtual environment (optional but recommended).
3. Install dependencies (example):
   ```bash
   pip install numpy pandas matplotlib jupyter
   ```
4. Start Jupyter:
   ```bash
   jupyter notebook
   ```
5. Open any `.ipynb` file and run cells top-to-bottom.

### Option 2: View on GitHub
You can directly preview notebooks in the GitHub UI without running them.
